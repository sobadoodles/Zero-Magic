# Code Review Checklist

- [ ] Changes match the stated scope.
- [ ] Code is understandable, with no duplicated setup.
- [ ] Inputs are validated.
- [ ] Missing records and invalid operations return appropriate errors.
- [ ] Tests cover successful behavior and relevant failure cases.
- [ ] Tests pass locally.
- [ ] No secrets, virtual environments, or unrelated files are included.
- [ ] Known limitations and remaining work are documented.
