# Feature: Create a card

## Goal
Let a client create a work card through the API.

## Endpoint
POST /api/v1/cards

## Input
- title: required string; must not be blank after trimming whitespace
- goal: required string; must not be blank after trimming whitespace
- acceptance_criteria: optional list of non-blank strings; defaults to []
- out_of_scope: optional string; defaults to ""

## Server-controlled fields
- id: generated by the server
- stage: always "Spec" for a new card
- assignee: initially null

Clients cannot set these fields during creation.
Unexpected input fields are rejected.

## Acceptance criteria
1. Valid input returns HTTP 201 and the created card.
2. The response contains all input and server-controlled fields.
3. Each created card gets a unique ID.
4. Leading and trailing whitespace is removed from title and goal.
5. Missing, blank, or incorrectly typed required fields return HTTP 422.
6. Invalid input does not create a card.
7. Created cards are stored in memory for later retrieval.

## Out of scope
- Changing stages
- Assignment
- Comments
- Database storage
- Authentication
